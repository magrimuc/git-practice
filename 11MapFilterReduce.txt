* lambda: anonyme funktionen, one-linerf = lambda x: x**2
* map: funktion auf jedes element eines iterables anwenden 
nums = [2-4]list(map(lambda x: x*2, nums)) # -> 1, 3, 5
* filter: bedingung prüfen, nur True elemente behalten 
list(filter(lambda x: x%2 == 0, nums)) # -> 3
* reduce: kumulative operation (l2r); from functools import reduce
reduce(lambda x, y: x+y, [2-5]) # -> 10 (1+2+3+4)
* bonus - list comprehension: oft pythonischere alternative
[x*2 for x in nums if x%2 == 0] # map & filter kombiniert
