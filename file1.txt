3) feature branch
"git branch feature" - legt branch feature  (ohne "feature": zeigt branches an)
"git checkout feaure" - wechselt zum branch
arbeiten (Dateien verändern, committen)
"git checkout main" - wechsel zu main
"git merge feature" - merge feature (i.e. commit der changes aus branch)

5) (versuche) eine einmal geaddedte Datei zu vergessen.
Problem: git push läuft auf Fehler, weil Datei zu groß (100 MB) f github.
ABER lokales repo hat die große Datei drin (irgendwo hängend)...
Bis das repo sie vergißt muss man:

$ git reset HEAD dataset/*
$ git rm --cached dataset/ratings.csv
$ git filter-branch --force --index-filter 'git rm --cached --ignore-unmatch dataset/ratings.csv' HEAD~3..HEAD
$ git rm --cached dataset/ratings.csv

der nun folgende commit (mit .ignore) ist suffizient, einen vernünftigen status herbeizuführen - ohne rm cached reichte es in ersten Erfahrungen nicht...
